# Commands in Telegram

- Click “+ Command”, enter a name starting with /, . or !, and write a reply.
- Type the command in a Telegram draft and press Space. The three prefixes are interchangeable.
- Select a suggestion using the arrow keys, then press Tab or Enter. You can also click a row. Esc closes the suggestions.
- Ctrl+Shift+B captures the whole draft. To capture a selection, copy it in Telegram and use “Paste from clipboard”.

# Search and filters

- Search matches commands, descriptions and the text of every variant. You can omit the command prefix.
- The filter next to search shows all templates, favorites or one folder. Add or remove folders in Settings.
- The star adds a template to favorites. Uncheck an item to disable its command in Telegram. It stays in the library and search results.

# Backups

“Export JSON” saves your templates and folders to a file. “Import JSON” replaces the current library after confirmation.
