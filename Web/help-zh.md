# 在 Telegram 中使用命令

- 点击「+ 命令」，输入以 /、. 或 ! 开头的名称，再输入回复内容。
- 在 Telegram 草稿中输入命令并按空格键。三个前缀可以互换。
- 用方向键选择提示，再按 Tab 或 Enter 确认，也可以点击条目。按 Esc 关闭提示。
- Ctrl+Shift+B 可获取整个草稿。若只需要一部分，请在 Telegram 中复制选中的文字，再点击「从剪贴板粘贴」。

# 搜索和筛选

- 搜索会匹配命令、说明及所有回复版本的内容。输入命令时可以省略前缀。
- 搜索框旁的筛选器可显示所有模板、收藏或某个文件夹。在「设置」中添加或删除文件夹。
- 点击星标收藏模板。取消勾选后，命令在 Telegram 中停用，但仍可在模板列表中找到。

# 备份

「导出 JSON」将模板和文件夹保存到文件。「导入 JSON」会在确认后替换当前的模板库。
